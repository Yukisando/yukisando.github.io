ColdSnap email signatures

To use one: press its Copy button, then paste it.
  1. Gmail (on a computer): Settings → See all settings → General → Signature → Create new → click in the box → Ctrl+V → Save changes at the bottom. Under "Signature defaults", pick it for each "From" address.
  2. Outlook: Settings → Mail → Compose and reply (new Outlook / web), or File → Options → Mail → Signatures (classic) → New → Ctrl+V → Save.
